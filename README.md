# vclient — сетевой клиент (курсовая работа ТиМП, вариант 18)

Клиентская программа для клиент-серверной системы обработки данных.
Читает числовые векторы из текстового файла, проходит аутентификацию на сервере,
передает векторы на сервер и сохраняет полученные результаты в двоичный файл.

| Параметр варианта 18      | Значение               |
|---------------------------|------------------------|
| Файл исходных данных      | текстовый              |
| Файл результатов          | двоичный               |
| Тип данных                | `uint64_t`             |
| Хеш-функция               | SHA-1                  |
| Кто формирует соль        | сервер                 |

## Быстрый старт

```bash
# 1. установить компилятор и библиотеки (Ubuntu / Debian)
sudo apt install build-essential libboost-program-options-dev libcrypto++-dev

# 2. скачать и собрать
git clone https://github.com/doposle147-lang/vclient-variant18.git
cd vclient-variant18
make

# 3. справка
./vclient -h

# 4. запуск (сервер должен быть запущен)
./vclient -a 127.0.0.1 -i input.txt -o out.bin -c vclient.conf
```

Пример файлов `input.txt` и `vclient.conf` — ниже, в разделах «Файл исходных данных» и «Файл конфигурации».

## Требования

- ОС с ядром Linux (проверялось в Ubuntu под WSL2)
- компилятор `g++` с поддержкой C++17, `make`
- библиотеки Boost.Program_options и Crypto++

Установка зависимостей в Ubuntu:

```bash
sudo apt install build-essential libboost-program-options-dev libcrypto++-dev
```

## Сборка

```bash
make          # собрать программу vclient
make clean    # удалить результаты сборки
```

## Запуск

```
vclient -a АДРЕС -i ВХОДНОЙ_ФАЙЛ -o ВЫХОДНОЙ_ФАЙЛ [-p ПОРТ] [-c КОНФИГ]
```

| Параметр          | Назначение                                   | Обязательный | По умолчанию             |
|-------------------|----------------------------------------------|--------------|--------------------------|
| `-a`, `--address` | IPv4-адрес сервера                           | да           | —                        |
| `-p`, `--port`    | порт сервера                                 | нет          | `33333`                  |
| `-i`, `--input`   | текстовый файл с исходными данными           | да           | —                        |
| `-o`, `--output`  | двоичный файл для результатов                | да           | —                        |
| `-c`, `--config`  | файл с логином и паролем                     | нет          | `~/.config/vclient.conf` |
| `-h`, `--help`    | справка                                      | нет          | —                        |

При запуске без параметров или с `-h` выводится справка.

### Файл исходных данных (текстовый)

Первая строка — количество векторов, далее в каждой строке размер вектора и его значения.
Числа целые без знака, разделяются пробелами.

```
3
3 1 2 3
2 18446744073709551615 5
1 42
```

### Файл конфигурации

Одна строка вида `LOGIN:PASSWORD`, например:

```
user:P@ssW0rd
```

### Файл результатов (двоичный)

| Поле                | Размер              | Тип        |
|---------------------|---------------------|------------|
| количество результатов | 4 байта          | `uint32_t` |
| результаты          | по 8 байт каждый    | `uint64_t` |

Просмотреть содержимое можно командами:

```bash
od -A d -t u4 -N4 out.bin      # количество результатов
od -A d -t u8 -j4 out.bin      # сами результаты
```

## Протокол взаимодействия с сервером

1. Клиент устанавливает TCP-соединение.
2. Клиент передает `LOGIN`.
3. Сервер передает `SALT16` (16 шестнадцатеричных цифр) или `ERR` и разрывает соединение.
4. Клиент передает `HASH = SHA-1(SALT16 || PASSWORD)` в шестнадцатеричном виде.
5. Сервер передает `OK` или `ERR` и разрывает соединение.
6. Клиент передает количество векторов (`uint32_t`). Начиная с этого шага обмен двоичный.
7. Клиент передает размер вектора (`uint32_t`).
8. Клиент передает значения вектора одним блоком (`uint64_t`).
9. Сервер возвращает результат по вектору (`uint64_t`).
10. Шаги 7–9 повторяются для всех векторов.
11. Клиент закрывает соединение.

## Структура проекта

| Файл                          | Класс            | Назначение                                     |
|-------------------------------|------------------|------------------------------------------------|
| `main.cpp`                    | —                | точка входа, перехват исключений               |
| `interface.h/.cpp`            | `UserInterface`  | разбор командной строки, управление работой    |
| `config_reader.h/.cpp`        | `ConfigReader`   | чтение логина и пароля                         |
| `data_reader.h/.cpp`          | `DataReader`     | чтение векторов из текстового файла            |
| `communicator.h/.cpp`         | `Communicator`   | сетевое взаимодействие с сервером              |
| `authenticator.h/.cpp`        | `Authenticator`  | вычисление хеша SHA-1                          |
| `data_writer.h/.cpp`          | `DataWriter`     | запись результатов в двоичный файл             |
| `errors.h`                    | `ProgramError` и наследники | классы ошибок                       |

## Обработка ошибок

При ошибке программа завершается с кодом 1 и выводит в stderr тип ошибки,
функцию, в которой она произошла, значения параметров и причину. Пример:

```
Тип ошибки: FileError (ошибка работы с файлом)
Где произошла: DataReader::read(path=nofile)
Причина: не удалось открыть файл для чтения
```

## Проверка с тестовым сервером

Тестовый сервер из репозитория https://gitlab.com/winwood/timp (каталог `server`):

```bash
./server -T uint64_t -H SHA1 -S server                          # в первом терминале
./vclient -a 127.0.0.1 -i input.txt -o out.bin -c vclient.conf  # во втором
```

Тестовый сервер принимает логин `user` и пароль `P@ssW0rd`.
